# 走れ!手作りモーターカー

エナメル線、釘、整流子、ブラシ、磁石で手作りDCモーターを組み立て、ギヤ・車輪・シャーシと組み合わせてコースを走らせるチューニングゲームです。

高回転だけを目指すのではなく、トルク、ギヤ比、車輪径、質量、グリップ、発熱の釣り合いを、走行結果と生の計測値から探ります。対象は、手作りモーターや工作車で遊んだ経験のある大人です。

## 主な機能

### ガレージとモーター工作

- 線径・巻き方・巻き数・ワニス・軸ずれ・整流子・ブラシ圧・磁石距離を調整
- 実物の工作手順に沿った8工程のモーター組み立て
- シャーシ・ギヤ・車輪・タイヤ・電池位置・カラーの選択
- 車体を含む構成をチェックサム付き`MC2-`レシピコードで共有
- v1.5の`M15-`モーターレシピを読み込み可能

### テスト走行と5コース

標準直線で現在の構成を確認できるほか、性質の異なる5コースに通常条件とEX条件があります。

- 10 m直線: 加速と最高速
- 坂道: トルク、ギヤ比、質量
- カーブ: 速度、重心、路面グリップ
- でこぼこ道: 車輪径、駆動力、始動性
- 省エネ走行: 電流、内部抵抗、各種損失

走行中は速度、回転数、電流、発熱、空転、区間情報を表示します。走行後は正式な消費エネルギーと「内訳（概算）」を分けて確認できます。

### 実験ノートと実験室

- 走行条件・乱数シード・計測結果・時系列を自動記録
- 2件の記録をA/B比較
- 車輪を浮かせた無負荷試験と、接地させた負荷試験を切り替え
- SI単位付きの連続パラメータでモーターと車体を詳しく検証

記録はブラウザの`localStorage`に保存します。バックエンドや外部通信は使用しません。

### トラブル診断

故障した工作車の計測値と走り方を観察し、原因となる調整箇所を特定します。答えを直接示す段階ヒントではなく、電流・回転・発熱・空転などの観測事実を判断材料にします。

## 物理モデル

物理エンジンはReactやDOMから独立した純粋なTypeScript関数です。固定タイムステップ`1/120 s`で、次の挙動を数値計算します。

- 整流、逆起電力、コギング、静止摩擦、接触不良、短絡
- 電池内部抵抗、発熱と放熱、無ワニス時のコイル崩壊
- ギヤ効率、反射慣性によるモーターと車体の連成
- 転がり抵抗、空気抵抗、坂、路面、でこぼこ、カーブ安定性
- タイヤ空転時の2自由度化と、エネルギーを増やさない再結合

回転数が高いだけでは速くならず、同じモーターでもギヤや車輪を変えると加速・最高速・登坂力が変化します。

## 操作と表示

マウス、タッチ、キーボードに対応し、スマートフォンの縦画面でも操作できます。状態は色だけに依存せず、文字や記号も併用します。

走行音は初期状態でミュートです。画面上の音声ボタンで有効化し、音量スライダーで調整できます。

## PWA・オフライン

対応ブラウザではホーム画面へ追加できます。一度読み込んだアプリ本体はService Workerにキャッシュされ、オフラインでも起動できます。走行記録や設定は端末内だけに保存されます。

## ローカル実行

```bash
npm install
npm run dev
npm run test
npm run build
npm run lint
npm run sweep
```

バックエンドを持たない静的サイトで、GitHub PagesやVercelへ配置できます。

## 安全上の注意

実物の電池を短絡させないでください。短絡は発熱、液漏れ、破裂の原因になります。発熱した電池や導線には触れず、電源を外してください。刃物、ニッパー、熱工具などを使う工作は、製品の注意事項に従い、安全な場所で行ってください。

本作の計測値と故障表現はシミュレーションであり、実物の安全を保証するものではありません。
