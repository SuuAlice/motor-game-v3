# 回れ!手作りモーター EX

エナメル線、釘、整流子、ブラシ、磁石で作る手巻きDCモーターを、数値と挙動の両面から追い込むチューニングシミュレーターです。

対象は、子供の頃に手作りモーターやミニ四駆で遊んだ大人。線径、並列巻き、巻き数、整流子、ブラシ圧、磁石距離を調整し、計測・記録・比較を繰り返して性能の最適点を探します。

物理エンジンは整流、逆起電力、静止摩擦、接触不良、コギング、電池内部抵抗、発熱、コイル崩壊を固定タイムステップで数値積分します。ReactやDOMに依存しない純粋なTypeScript関数として実装し、性質ベースのテストで検証しています。

## 主な機能

### 実験室

すべてのパラメータをSI単位付きのスライダーと数値入力で操作できます。RPM、電流、逆起電力、発熱、瞬断、RPM変動係数、停止角度分布をリアルタイムに計測します。

導出量としてコイル抵抗、接触抵抗、慣性モーメント、巻き数上限を表示します。線径や並列本数を変えると、巻き数上限も物理的な巻きスペースに合わせて変化します。

### 実験ノート

始動からリセットまでを1セッションとして自動記録します。

- MotorConfig全値と乱数シード
- 定常RPM、平均・最大電流、RPM変動係数、最大発熱
- 短絡、過熱、コイル崩壊イベント
- 間引き保存した時系列
- 記録時のモーター回転アニメーション
- 2セッションのA/Bグラフ比較と差分表
- JSON書き出し・読み込み

保存先はブラウザの `localStorage` (`v15:notebook`)です。外部通信は行いません。

### モーターレシピ

MotorConfigと乱数シードを、`M15-`で始まるチェックサム付きレシピコードへ変換します。同じレシピは同じ条件で再現でき、文字列を手動で共有できます。破損・改変されたコードは理由付きで拒否し、範囲外の値は物理範囲へ補正します。

### チャレンジ

v1.0の7チャレンジを「クラシック」として新物理で再計算し、さらに複合条件を持つEXチャレンジを4件追加しています。

評価は星ではなく、全条件の達成／未達成と自己ベストです。回転数だけでなく、最大電流、発熱、RPM変動係数、コイル崩壊の有無を同時に管理する必要があります。

### トラブル診断

故障したモーターの計測値を観察し、操作可能な1パラメータから原因を特定します。段階ヒントは表示せず、ObservationPanelには計測事実だけを表示します。

### 組み立て

線径・並列本数の選択、コイル巻き、ワニス固め、軸固定、整流子加工、台座、磁石・電池の組み立てを順に行います。最後はCanvasをフリックして始動します。ワニスを省略した高回転レシピではコイル崩壊が起こり得ます。

## ローカル実行

```bash
npm install
npm run dev
npm run test
npm run build
npm run lint
npm run sweep
```

Node.js 20以上を推奨します。バックエンドを持たない完全な静的サイトで、GitHub PagesやVercelへ配置できます。

## 安全上の注意

実物の電池では絶対に短絡させないでください。本作の発熱表示はシミュレーションですが、実物の短絡は発熱、液漏れ、破裂の原因になります。
