5. 報告すべき観測事項 2件(いずれも判断が要ります)
════════════════════════════════════════
**O-1: finish時刻はratioに対して単調ではありません(局所逆転あり)**
承認式の`tensionPackingRatio`は単調非減少で、**式の契約は満たしています**。しかし**走行結果は局所的に逆転します**——`minP=0.9, ref=1.0`の257点で、隣接点の**122/256組**が「ratioを上げたのにfinishが遅くなる」向きでした。
```
最大の局所逆転: +0.5083 s   ratio 0.923828(22.6167s) → 0.924219(23.1250s)
最速は ratio=0.998828 の 20.0500 s で、ratio=1.0(20.2417 s)より0.19 s速い
粗い刻み(9点)では単調: 24.242 → 23.558 → 22.708 → 22.233 → 21.833 → 21.250 → 20.850 → 20.617 → 20.242
```
原因はdtの離散化と`axisOffsetMm=1.2`由来の振動ノイズ(run RNG)と見られ、**大域的な傾向は明確に単調**です。ただし**「強く張ったのに遅くなった」が1/256刻みでは起こりうる**という事実は、体験の設計判断に関わるため報告します。緩和したい場合の選択肢(いずれも未実施・要承認)は、(i)受容して大域傾向のみを設計意図とする、(ii)UIの張力操作粒度を1/256より粗くする(brabit所有)、(iii)`axisOffsetMm`を0にした条件で再測して寄与を切り分ける、です。**私の推奨は(i)**——0.5 s未満の逆転は、そもそも同じ巻きを2回走らせても出うる範囲であり、ここを消そうとすると乱数や振動という既存の設計要素へ踏み込むためです。

**O-2: 実用域が`minPackingRatio ∈ [0.824, 1.0)`と狭く、承認済み候補空間(0.1刻み)では1点しか入りません**
完走下限`0.823437`のため、承認された5点(0.5/0.6/0.7/0.8/0.9)のうち**通過するのは0.9だけ**です。刻みが下限に対して粗く、**0.83〜0.89の帯が未探索**のまま残っています。P4-0 G3で「刻みが最小有効粒度に達していないのに候補なしと結論しない」と差し戻された教訓に照らすと、ここは**候補空間の拡張(例: minP ∈ {0.83,0.85,0.87,0.89})を追加で回す価値があります**。ただし候補空間は承認バンドルの一部なので、**私の判断では拡張せず、指示を仰ぎます**。拡張すると張力による性能差をより大きく(最大約20%→それ以上)取れる可能性があります。
