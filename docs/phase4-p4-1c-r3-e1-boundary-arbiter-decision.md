## 1. 正式裁定

受入条件(d)は破断述語の境界意味論を検証する条件である。

1. `exposure == E_BREAK`の厳密等号では非破断とする。
2. `T_SAFE + 1/256`では超過増分が厳密に正となり、exposureが単調増加して理論上有限turnで破断する。
3. +1量子超過が`MAX_WINDING_TURNS=150`以内に実破断することは要求しない。

実用到達性は別の受入条件「最大張力で150turn以内に破断」が担う。+1量子にも150turn以内の破断を要求すると、`E_BREAK <= 150/256 ≈ 0.586`となり、最大張力で約3turnの即死設計になるため、気付けるが即死ではないという選定意図と衝突する。

理論破断turn `257 / 513 / 769 / 1025 / 1537`は、`E_BREAK={1,2,3,4,6}`に対する`256 * E_BREAK + 1`および`floor(E_BREAK / (1/256)) + 1`と全件一致する。承認格子外を探索せず停止した判断は正しい。
