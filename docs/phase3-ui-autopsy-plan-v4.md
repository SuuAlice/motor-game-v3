## 6. 破壊発生時の遷移フロー(v4: engineのstage/endReasonに従う)

**UIはmode IDだけで終端/非終端を判定しない。engineが返すstage(モード内の進行段階)とRunOutcome.endReason(走行終了理由)にのみ従う**(レビュー項目15)。UIは独自の閾値・独自の停止条件を持たない。

### 6-A. 非終端stage(走行継続)

例: D01進行、D02発煙段階、D04膨張・発煙段階、D05スパーク、D06歯欠け進行(全損未満)、D07可逆熱ダレ・不可逆減磁(いずれも走行は継続。図鑑登録可否のみ異なる)、D09摩擦増段階。

1. engineから該当`DestructionState`のstage更新イベントを受信するたびに、走行画面のHUD領域へ症状表示を反映する。走行は継続する
2. 図鑑への初回登録・詳細画面への遷移は、走行終了(6-B節)まで行わない。走行中に図鑑詳細画面へ割り込み遷移させない

### 6-B. 走行終了(通常完走・終端stage到達・手動中断のいずれか)

**結果反映はボタン操作を待たず、走行終了の瞬間に自動で行う**(レビュー項目14)。

1. **走行終了判定**: 次のいずれかでengineが走行終了(`RunOutcome`確定)を通知する: (a) 通常完走、(b) 終端stage到達(D02発火・D03破裂・D04炎上・D06全損=走行不能・D09焼付き等、engineのendReasonに従う。mode ID一覧をUI側にハードコードしない)、(c) プレイヤーによる手動中断・モード変更。いずれの場合もそこまでに発生済みの劣化差分・図鑑候補を一度だけ確定する
2. **結果反映(自動・即時)**: `RunOutcome`確定を受けて、storeの単一アクションを直ちに1回呼び出す。このアクションが個体劣化・破壊消費・図鑑初回登録・初回報酬・実験ノート記録を原子的に適用する。UIコンポーネントは結果の成否(成功/失敗)のみを受け取る。**この時点でreload・タブ終了しても結果は失われない**
3. **停止画面の保持(終端stageの場合のみ)**: 終端stageで走行が終了した場合、走行画面はその場で停止し、破壊演出と症状を表示したまま自動では次画面へ遷移しない。プレイヤー操作「検死レポートへ」を押すまで停止画面を維持する(既決方針を継続)。このボタンは**すでに確定済みの結果を見に行くだけ**で、経済・在庫には触れない
4. **反映失敗時**: 手順2が失敗した場合、停止画面(または対応するリザルト画面)に保存失敗を明示し、安全な再試行手段を提供する。失敗したまま図鑑詳細画面へは遷移させない
5. **図鑑詳細画面への遷移**: 新規発見が0〜1件の場合、「検死レポートへ」操作後に当該D0x詳細画面(5節)へ直行する。2件以上の場合は6-C節の発見一覧を経由する
6. **ガレージへ戻る**: 図鑑詳細画面での確認操作後は既定フローでガレージへ戻る。図鑑一覧・発見一覧経由でこの画面を開いた場合は、確認操作は遷移元へ戻す(遷移元を状態として保持、10節)

通常完走(非終端のみ、または破壊なし)の場合も手順1・2は同様に実行されるが、手順3の停止画面は発生せず、既存の通常リザルト画面上で結果(新規発見があれば6-C節)を表示する。

### 6-C. 複数モード同時発見時の導線(v4新設、レビュー項目16)

D03/D04の排他を除き、同一走行で複数モードが成立しうる。

1. 走行終了時点(6-B節2)の原子的反映結果に、新規発見が2件以上含まれる場合、まず「今回の発見一覧」画面を表示する(発見したD0xのサムネイル+モード名を新規発見数ぶん列挙)
2. 各項目を選択すると当該D0x詳細画面(5節)を閲覧できる。詳細画面からの「戻る」は発見一覧へ戻る
3. 報酬は画面の閲覧回数に関係なく、6-B節2の走行終了時点の原子的反映で全新規発見分が一括付与済みである。詳細画面の報酬ブロックは「付与済みの記録」を表示するだけ
4. 発見一覧を最後まで確認(または個別に確認済みマークが揃う)した後の確認操作でガレージへ戻る
