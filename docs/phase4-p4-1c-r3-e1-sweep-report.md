## 3. 受入条件(d)の確認点

`tension = T_SAFE + 1/256`では`x = 1/256`であり、最初の破断turnは次のとおり。

```text
E_BREAK=1 -> 257
E_BREAK=2 -> 513
E_BREAK=3 -> 769
E_BREAK=4 -> 1025
E_BREAK=6 -> 1537
```

したがって、+1量子超過はexposureを正に増やし有限turnで破断するが、`MAX_WINDING_TURNS=150`以内には破断しない。150turn以内を必須とするなら`E_BREAK <= 150/256 ≈ 0.586`が必要で、承認済み格子外となるため探索していない。

補足裁定を求める二択:

1. 受入条件(d)を述語境界（等号では蓄積0、+1量子では蓄積が正となり理論上有限turnで破断）として扱う。
2. +1量子でも構築可能な150turn以内の破断を要求し、現格子を不成立として再設計する。
