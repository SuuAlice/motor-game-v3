# P4-0 G7 AIデバッガー向け機能確認依頼

## 目的

P4-0 G7のうち、AIによる画面操作で客観確認できる機能配線だけを確認してください。

これはゲーム性の最終判定ではありません。次の主観項目は人間プロジェクトリードが別途判定します。

- 操作が苦役か
- 数値を見る前に改善を感じるか
- 自分で原因の仮説を立てられるか
- もう一度遊びたいか

音はPhase 6へ繰り越したため、確認対象外です。

## 対象

- repository: `https://github.com/SuuAlice/motor-game-v3`
- branch: `codex/p40-g7-debug-handoff`
- 基点: `4fefebe09f3407910091327d21d08075d0cf9084`
- ブランチ先端をそのままcheckoutし、ローカル変更を加えず確認してください。

## 禁止事項

- コード・docs・テスト・物理式・較正値・公開契約の変更
- commit・push・PR作成・merge・tag・release
- localStorageや内部stateの直接書換えによる進行
- DevToolsから関数を直接呼ぶこと
- 結果を期待値へ合わせるための操作や報告の改変

## 起動

```bash
git clone --branch codex/p40-g7-debug-handoff --single-branch https://github.com/SuuAlice/motor-game-v3.git
cd motor-game-v3
npm ci
npm run dev -- --host 127.0.0.1 --port 5176
```

5176番が使用中なら、空いている別ポートを使い、報告へ実際のURLを記載してください。新規ブラウザプロファイルまたはシークレットウィンドウを使います。

タイトル画面の「巻線プロトタイプ(保存されません)」から専用画面へ入ってください。

## A. 3入力案の客観確認

同じブラウザ・viewportで次の3案を各1回、30ターンまで操作してください。案ごとに「案の選択へ戻る」で戻ります。

### A1. 生ドラッグ

- パッドを周回ドラッグしてターンが増えることを確認します。
- 操作自動化が不安定な場合は「1ターン記録」を30回押して構いません。その場合はボタン経路を使ったと明記してください。
- 巻数が`30 / 30`で止まり、31ターン目を追加できないことを確認します。

### A2. 半自動治具

- 「始動」で1秒につき1ターン増えることを確認します。
- 一時停止中に巻数が増えないことを確認します。
- ガイド・張力・方向反転が表示へ反映されることを確認します。
- 30ターンで止まり、「この巻線で走る」が有効になることを確認します。

### A3. パターン設計

- 4制御点の位置・張力、3区間の腕・方向を操作できることを確認します。
- 「実行して30ターン展開」で一度に`30 / 30`になることを確認します。
- 31ターン目へ進まないことを確認します。

各案について、完了可否、表示された経過秒、操作不能、Consoleの赤エラーを記録してください。楽しさ・疲労感の採点は不要です。

## B. 半自動治具の垂直スライス

可能なら、次の代表経路で「初走敗北→一区間修正→二走目勝利」まで確認してください。タイミングがずれた場合は結果を改変せず、実際の巻線構成と結果を報告してください。

### B1. 初走用30ターン

半自動治具の操作領域へフォーカスし、次を行います。

1. 初期位置0.5から`A`を6回押し、表示が左腕になったことを確認します。
2. Spaceまたは「始動」で開始します。
3. 巻数10になった直後に`R`を押して逆方向へ切り替えます。
4. 巻数11になった直後にもう一度`R`を押し、順方向へ戻します。
5. 巻数21になった直後に`D`を12回押し、表示が右腕になったことを確認します。
6. 30ターンまで待ちます。

意図した構成は左21・右9、0始まりのturn 10だけ逆巻きです。UI操作のタイミングでずれた場合はやり直して期待値へ合わせず、その事実を報告してください。

### B2. 初走と第一段・第二段

1. 「この巻線で走る」を押します。
2. playerと相手ゴーストが同じ10メートル直線を走ることを確認します。
3. 走行終了後、写真判定の静止画・勝敗・差だけが先に表示されることを確認します。
4. 操作しなければ約2.5秒後に詳細へ自動遷移することを確認します。
5. 別走行では「くわしく見る」で即時遷移でき、遅れて二重遷移しないことを確認します。
6. 詳細に4区間の所要時間と巻線クローズアップが表示されることを確認します。
7. 詳細内の再生に、押しても反応しない「結果へ進む」ボタンが存在しないことを確認します。

代表構成では初走player約22.417秒、rival約21.342秒で敗北します。表示は丸められても構いません。異なる場合は実値を報告し、期待値に合わせないでください。

### B3. 一区間修正と二走目

1. 「前の巻線を複製して一区間を巻き直す」を押します。
2. 第2区間を選びます。
3. 区間外は値そのままと明記され、第2区間分だけ入力待ちになることを確認します。
4. 初期状態が順方向であることを確認し、`A`を6回押して左腕にします。
5. 始動し、要求されたターン数まで全ターンを順方向で巻きます。
6. 「この区間を確定する」→「2走目を走らせる」と進みます。
7. 二走目の写真判定・詳細が表示されることを確認します。
8. 勝利した場合、「銘板をつくる」が表示され、愛称・最終タイム・相手との差・巻線表示へ進めることを確認します。
9. 「おわりにする」→「もう一度巻く」で新しい回へ戻れることを確認します。

代表構成では二走目player約20.242秒、rival約21.342秒で勝利します。異なる場合は実値をそのまま報告してください。

## C. 負例・境界

- 巻線途中では「この巻線で走る」が無効
- 巻き直し途中では「この区間を確定する」が無効
- 選択区間外の表示値・ターン数が変化しない
- リセットで現在の試作sessionが初期化される
- タイトルへ戻る／再読み込みで銘板と試作結果が残らない
- Consoleにアプリ由来の赤エラーがない
- 可能なら横長・縦長viewportで操作不能や表示切れがない
- 狭いviewportで「等倍でも収まりません」が出た場合は既知事項としてviewport寸法を記録し、そこで全体をFAILにしない
