# Fable較正レビュー: P3-3 checkpoint 5(統合較正閉包) — 値群ごとの判定+Gate 6解禁条件

【判定1: 各候補値の採否】

D02 conductionScale=0.04・dissipationCoefficient=0.5: 採用確定。3×3 grid実測は較正証跡として模範的である——受け入れ領域の全域を可視化し、採用点が境界でなく内部(NORMAL余裕74%、高負荷到達10.05秒=レース時間内)に座ることを示した。「到達可能性が等価ゲインkだけでなくconductionScaleの絶対値に依存する」という観測を断定なしに記録した規律も正しい。参考として解釈を一つ提供する(採否に影響しない): ゲージの平衡値はk×coilLossWであり、到達可能性は概ね「高負荷時のk×coilLossWが1.0を超えるか」で説明できる——0.02系列の全滅と0.04/0.8の不達はこの平衡条件で整合する。実装コメントに残すかはalice裁量でよい。

D02 smokeResistanceMultiplier=1.2: 採用確定。方向実測(no-op比でburnout到達を加速、1.0側は1000step走ってもratio 0.921)は設計意図と整合する——「煙が出たまま走り続ければ燃える」は、プレイヤーに停止判断の意味を与える診断的に正しい世界であり、瞬間coilLossWの低下と趨勢の増加が分岐するという非自明な連成を捏造なしに報告した点も良い。難易度哲学(原因は断定しない・事実は見せる)との矛盾はない。

D05共通5値: 採用確定。brushSparkDurationLimitS=0.15のバースト内frame17到達・0.2秒上限のframe23ちょうど境界・超過値の構造的非到達という三点固定は、0.4節#12の到達可能性制約の完全な機械検証である。recovery 6/1.2のno-op否定(実電流1.6379→1.6052A)も充足。brushSparkCurrentThresholdA=3はNORMAL全15組合せのepisode 0と高負荷での全event閾値超過assertの対で弁別機能が直接実証されており、間接扱いは謙遜である。wearPerAmpSecond=0.001は高負荷5秒で摩耗5〜12%という経済スケール(虐待走行4〜8回でブラシ寿命)として妥当。付帯条件1: Q15-3の累積摩耗3値(0.056354/0.076636/0.117902)が数値回帰(toBeCloseTo等)として固定済みであることを確認し、未固定なら固定する——これがwearPerAmpSecondの直接証跡を兼ねる。

ブラシ8値: 採用確定。Q15-2両極実測(差率38.35%、閾値5%を大幅超過)とQ15-3の3条件完全実測(順位逆転・閾値超過の直接assert・銅板超え副次帰結の明示報告)は、私が課した受け入れ条件をすべて満たす。個別sweepのない2値の扱い: (i)銀黒鉛contact 0.7は両極が実測済みの単調中間値であり、個別sweepは不要——付帯条件2: 接触抵抗の4素材順位(1.3>1.0>0.7>0.5)がmapping層の単体テストで固定されていることを確認(12.5節DoDの全素材網羅に含まれているはずの確認のみ)。(ii)貴金属chatter 0.7はQ15-3でepisode数がcarbonと同数(6)であり、効果の存在自体が一度も単離実証されていない——付帯条件3: 同一rng列・同一構成でratio 0.7と1.0のnextChatterState経由バースト発生数を比較する決定論harnessテストを1本追加し、0.7が実際にバースト頻度を下げることを固定する(値の変更は不要、効果の存在証明のみ)。

D01 decayExposureScaleRad=1000・minEffectiveTurnsRatio=0.5: 保留——追加sweepを指示する(Gate 6開始を妨げる必須修正はこれ1件)。報告自身が正直に認めるとおり、値の大きさを支持する実測が存在しない。これはP3-1-Q1返済の中核数値であり、spec §7.1.1の「漸減」という文言の機械検証なしに確定させることはできない。受け入れ条件を指定する:

- 漸減性: 崩壊後の持続過回転構成で、effectiveTurnsRatioが1.0からfloorへ1秒未満で到達しないこと(段差ではなく漸減であることの検証。目安: floor到達に2秒以上の持続超過を要する)
- 観測可能性: 崩壊発生後、代表的構成の走行残余内に定常RPM(または電流)の低下が観測可能(目安3%以上、regressionDiff閾値との整合)であること——漸減が起きているのに誰にも見えない死に演出の防止
- floor到達可能性: 意図的な虐待構成(崩壊後も全開維持)でminEffectiveTurnsRatioへの到達が1走行内(目安10秒以内)に可能であること——0.5が到達不能な死に定数でないこと
- NORMAL_OPERATIONトリガなし(既存実測で充足済み)

現行値(1000/0.5)が1〜3を満たせばそのまま確定。満たさない場合はdecayExposureScaleRadを先に調整する(floorは「崩れた巻線の残存結合」という物理的意味が明確なため後)。

【判定2: 実測範囲の十分性】上記のD01追加sweep+付帯条件3件を除き、checkpoint 5の証跡は較正完了として十分である。grid方式・方向実測・境界三点固定・15組合せ拡張列・一時harnessの完全revert確認(grep TEMP_ゼロ)は、Step 9以来の較正規律の現時点での最良形と評価する。

【判定3: Gate 6解禁】D01追加sweepの充足+付帯条件3件の反映+Suu_mot3照合をもって解禁する。全候補値の人間commit承認をGate 6の前提にする必要はない——Q15-6で確定した経路(Fable候補裁定→sweep→確定申請→人間commit承認)のとおり、人間承認はP3-3最終レビュー後のcommit承認に包含される。D01 sweepが指定受け入れ条件を満たせばFable再提出は不要(実測全文を最終報告の確定申請表へ追記)。満たさず値を変更する場合のみSuu経由で変更値と実測を報告すること。
