## 0. 前提

- 試遊はG9完了後の最終コードで行う。feature gate(`productionWiringEnabled`)とV2旧経路は
  G9で削除済みであり、Phase 3のproduction経路が唯一の経路である。
- **起動手順**: `npm install`(初回のみ)→ `npm run dev` → ブラウザで
  http://localhost:5173/ を開く。本番相当で確認する場合は `npm run build` のあと
  `npm run preview`。保存はlocalStorageのみなので、記録を混ぜたくない場合は
  試遊前にlocalStorageを消すか、プライベートウィンドウで開く。
- 素材構成・入力手順・想定stepは、`src/store/__tests__/destructionWiring.test.ts`の
  **production入口(実UIと同じaction)での実測値**をそのまま引いている。推定値ではない。
  1 stepは物理1/120秒。想定時間は step ÷ 120 の目安であり、操作時間は含まない。
- 記載のない設定は初期装備・初期configのままとする。

### (3) 安全表示の確認

- 電池の短絡(D03/D04)を再現したあと、**車体テスト走行の画面**および**実験室の画面**の
  下部に、現実の安全注意(「実物の電池や導線を短絡させないでください。発熱した場合は
  すぐに接続を外してください。」)が出ていること。
- 発熱・発火の表現が「ゲーム内の演出」として閉じており、実機での模倣を促す文言が無いこと。

### 負例(9): 通常運用では起きないこと

- 上記のD01構成から**ワニスありへ戻す**と、同一構成・同一step数でも崩壊しないこと。
- 通常運用の構成(初期装備・標準config)で5コース×3電池を走り切り、
  破壊イベントが1件も出ないこと。特にD06の歯欠けが0本、D09が非発火であること。
