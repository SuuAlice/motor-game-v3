1. **目標画はアセットではない**。完成スプライト・出荷物・トレース元のいずれにも使わない。実装は手続き描画(art-spec §2.3)のみで行い、ビットマップの同梱はart-spec §10(スプライト画像ファイルの安易な追加禁止)のとおり行わない
2. **目標画は「質感・構図・密度の方向」の参考である**。生成画像は内部解像度480×270の約3.5倍で描かれ、48色パレット・16方位・ドット規律の外にある。到達目標のドット数・色数として読まないこと。可読性・成立性の判断は必ず**実寸480×270・パレット遵守のモック**で行う(Phase 1解像度比較の教訓)
3. チーム内ツールで生成した内部参照資料であり、出荷物に含めない(spec §15の整理)。リポジトリへは`docs/reference/`配下に下記の名前で配置することを推奨する

## 2. 正典適合性の判定記録

**既に正典どおりの要素(改定不要、目標画が正しく視覚化したもの)**:
- 自機=クリアボディで巻線が見える / ライバル=不透明カウルで外形のみ / ボスは撃破後に開示 —— **spec §6.2の既存仕様そのもの**
- クローズアップ(96px級)がモーターの格好よさを受け持つ役割分担 —— art-spec §5.1.1末尾の既定
- 緑=記録更新・成功のみ、黄=火花・警告のみ —— art-spec §3のパレット意味と一致
- 卓上世界の小道具(定規・鉛筆・マスキングテープ・カッターマット・ラジオペンチ・木目) —— art-spec §5.1会場カタログと一致

**目標画に含まれる正典違反(実装で必ず訂正するもの)**:
- 温度の℃表示(target-01/03) → 無次元HEATバー(spec §7.4。SI表示は温度較正ゲート完了後のみ)
- 速度「142 km/h」表示 → 表示は実SI値(spec §1.2「生の数値を見せる」)。スケール速度演出を採る場合は別途の仕様判断を要する(現時点では不採用)
- 解像度・色数・自由角 → 規則1・2のとおり

**責任者・議論での修正指摘(実装方針として記録)**:
- 目標画はまだ「巻線が整いすぎ・車体が製品的」。実装では**切断面の毛羽立ち・巻線の左右偏り・配線の取り回し・テープ補修痕・鉛筆線**をより強く出す(r3 §5.3「手癖の乱雑さがそのまま絵になる」の徹底)

## 3. 「形の文法」——車体を一枚絵でなく描画規則の合成として実装する

r3署名原則(spec §1.4)の実装方針。車体は固定デザインではなく、**個体データから決定論的に描画される独立規則の合成**とする(art-spec §2.3手続き描画の車体への適用)。分解:

| 描画規則 | 入力(個体データ) | 備考 |
|---|---|---|
| シャーシ外形 | シャーシ種(基本形: 二股ノーズのオープンフレーム実験車) | 「机上の実験機がスポーツカーへ育つ」路線の核 |
| 中央の手巻きローター | 巻線記録(spec §9.1) | 膨らみ・偏り・交差は記録から再構成(既定どおり) |
| 透明モーターカバー | ボディ素材(§4.2) | 操縦席ではない平たいカバー。クリア/不透明の観察差=§6.2 |
| 左右の電池 | 装備電池 | 種類・膨張度は既存art-spec §2.3の引数 |
| 後方の露出ギヤ | ギヤ素材・歯欠け | D06の欠けは見た目に出る(既定) |
| 車輪径の差 | 車輪構成 | |
| 四隅のガイドローラー | ローラー取付位置(§6.5/§9.3) | 位置がそのまま見た目の個性になる |
| 肉抜き穴 | 穴あけ記録(§9.3) | 配置=手癖(既定) |
| 損傷痕・補修痕 | 恒久劣化・被膜ダメージ・クラッシュ履歴 | 傷は履歴の可視化。第一条4(減磁は出さない)の例外規則は維持 |

- 多数の構成をエージェントに自動生成させ、**人間が「本当に自分の機体に見えるか」を選別する**——実装検証の方式として記録(P4-1/Phase 5の車体描画作業で使用)
- 自機基調色コバルトブルー+銅は**既定・広報基調色**であり強制ではない(塗装バンク art-spec §3によるプレイヤーカスタムは従来どおり)

## 4. 小縮尺識別キット(候補、D-CAM-1の判断に連動)

固定全体俯瞰(target-04系)を採る場合にart-specへ追加する候補。モック比較で成立性を検証してから確定する:
- 自機: 白の二重山形(シェブロン)マーカー+固有シルエット
- トラブルの読み: 発煙=市松ディザ煙、破片、姿勢変化、壁擦り=壁寄り姿勢+ローラー接点火花+短い擦過痕(いずれも既存パーティクル規約§6の適用で表現可能な想定)
- 大事故は画面を奪わない: 音+ミニアイコン通知(注目モードへの誘導のみ)
