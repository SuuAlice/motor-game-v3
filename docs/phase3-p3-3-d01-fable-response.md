# Fable補足裁定: P3-3 D01較正(floor到達可能性の未充足)

【裁定の核心】現行値decayExposureScaleRad=1000・minEffectiveTurnsRatio=0.5を維持したまま確定する。誤っていたのは値ではなく、私の受け入れ条件3である。 scale 200への変更も、追加の値探索も、モデルの見直しも行わない。

【所見: 自己制限フィードバックは意図挙動として受容する(必須回答2・3)】実測が発見した負のフィードバック——劣化→トルク定数低下→回転低下→COIL_DEFORM_OMEGA割れ→減衰停止——は、物理的に正しい創発挙動である。実物の巻線崩壊は過回転の遠心応力が駆動する。損傷が進めばモーターは自らの過回転を維持できなくなり、損傷の駆動源そのものが消える。「損傷が自分の原因を食い潰して止まる」のは実在系の性質であり、モデルの欠陥ではなくモデルが正直である証拠だ。特に構成20/10がω=188.8 rad/s——閾値209.4のわずかに下——で定常化した実測は、この系が「減衰が再開しない限界比率」へ自己組織化することを示しており、理論どおりの臨界収束である。P3-3-Q4(角速度超過分の積分)の再考は不要。駆動量を角速度以外へ変えることは、この物理的正直さを壊す方向にしかならない。本挙動をPhase 2の銅線+フェライト過熱レジームに続く、本プロジェクト2件目の創発的実測知見として台帳へ記録すること。

【受け入れ条件の改訂(条件3→3')】条件3「floor到達可能性」は、減衰が外部駆動されるという暗黙の仮定の上に私が書いた条件であり、実測はその仮定が自己駆動系では成立しないことを示した。要件が二律背反の隅(200前後の空虚なwindow)へ実装を追い込むとき、疑うべきは値ではなく要件である。 改訂後の受け入れ条件:

3'(プラトーの実測固定): 代表的虐待構成における自己制限プラトー(実測: 最良構成でratio 0.707、29%の結合喪失)が、観測可能な劣化(3%基準を大幅超過——条件2実測でratio 0.75時に定常RPM 30.4〜100%低下)を与えること。充足済み

1'(漸減性の直接形): floor到達時間はもはや漸減性の尺度にならないため、「崩壊トリガ後1秒時点でratio ≥ 0.8」を段差禁止の実測可能形とする。実測trajectory(数秒〜数十秒かけた減衰)から充足は明らかだが、下記の回帰テストでassertとして固定する

条件2(観測可能性)・条件4(NORMAL_OPERATION非トリガ): 充足済み(実測どおり)

【minEffectiveTurnsRatio=0.5の再定性(必須回答3・重点確認2)】floorの役割を「ゲームプレイ上の到達目標」から「数値安全域のclamp」へ改める——復元データの破損・将来のモデル変更・外部駆動に対して比率が正気の域を出ないことの保証である。値0.5の根拠(崩れた巻線の残存結合という物理的意味)は変わらない——役割が変わっただけで、前裁定との矛盾はない。あわせて重要な申し送りを1件: floorが初めてゲームプレイに現れうる唯一の経路は外部機械駆動(急な下り坂での逆駆動による過回転の外部維持)である。現行の実在5コースには存在しないため、vehicle/track文脈の追加sweepは不要(必須回答2への回答——負荷下ではωはさらに低く、崩壊後の持続過回転はむしろ起きにくい)。ただしPhase 5のコース設計申し送りへ「急降坂コースはD01減衰をfloorまで進めうる潜在挙動を持つ」と1行記録し、floorを死んだ定数ではなく文書化された潜在挙動にすること。

【Gate 6解禁条件(必須回答4含む)】次の3点をもって解禁する:

自己制限プラトーの数値回帰テスト1本を恒久追加: 最良構成(coilTurns 15/magnetDistanceMm 8)で、(i)プラトーratio≈0.7074のtoBeCloseTo固定、(ii)プラトー後のdecayExposureRad不増加(減衰停止の直接assert)、(iii)トリガ+1秒時点ratio≥0.8(条件1')。創発挙動を回帰で守り、将来の物理変更が静かにこれを壊すことを防ぐ
